# Status bar artwork

Hunger, happiness, energy, and cleanliness each have a separate icon frame and colored fill. These eight PNGs are prepared artwork only; no Unity scene, script, or gameplay has changed.

Frames have a 480x144 visible image on a 496x160 canvas. Fills have a 310x54 visible image on a 326x70 canvas. Each file has eight pixels of transparent padding. Frame interiors are transparent. Align and size the layers in the final interface before use.

The original sheet, prompt, preparation tool, and preview are kept in the [PocketPet repository](https://github.com/Zeref538/PocketPet/tree/main/source-art). This repository contains the lightweight finished PNGs. Artwork was created using the built-in image tool.
